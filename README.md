# JavaEE & Jakarta EE 10 Learning Labs

Repository containing practical implementation labs, architecture experiments, and hands-on exercises developed during my study of Jakarta EE 10 microservices and enterprise Java patterns.

## Repository Structure

* **Week-1-CDI-JAXRS-REST**: Component model, CDI 4.0 scopes and proxying, JAX-RS 3.1 REST API design, JSON processing, request pipelines, and Server-Sent Events.
  * **Day-01-CDI-Scopes-Lifecycle**: Multi-scoped bean hierarchy, lifecycle management, and CDI client proxying analysis.
* **Week-2-JPA-JTA-Security**: Data persistence with JPA 3.1, ORM entity mappings, JPQL, Criteria API, JTA transaction management, and stateless JWT authentication.
* **Week-3-BCE-Async-Performance**: Boundary-Control-Entity (BCE) design pattern, enterprise concurrency, asynchronous execution, and database connection pool tuning.

## Technical Environment

* Java 21 LTS
* Jakarta EE 10 Specs (`jakarta.*` namespace)
* Weld SE 5.1+ (CDI 4.0 Container)
* Apache Maven
